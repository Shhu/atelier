AI that stays at home

Une IA qui reste chez vous

The models are downloaded once, on first use, and run on your graphics card when it can (DirectML), otherwise on the processor.

Les modèles se téléchargent une fois, au premier usage, et tournent sur votre carte graphique quand elle le peut (DirectML), sinon sur le processeur.

  • Object Selection — hover an object to see it, click to select it, or draw a rectangle around it (SAM 2.1).
  • Select Subject and Remove Background in one click (BiRefNet).
  • Content-Aware Fill with an optional inpainting model (LaMa) for large areas.
  • AI Models window: what is installed, its size, where it runs, delete it anytime.
  • Sélection d'objet — survolez un objet pour le voir, cliquez pour le sélectionner, ou tracez un rectangle autour (SAM 2.1).
  • Sélectionner le sujet et Supprimer l'arrière-plan en un clic (BiRefNet).
  • Remplissage d'après le contenu avec un modèle de reconstruction optionnel (LaMa) pour les grandes zones.
  • Fenêtre Modèles d'IA : ce qui est installé, sa taille, où il tourne, à supprimer quand vous voulez.
